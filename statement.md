# Library management system

## Problem statement

-managing the book issue/return system manually , remembering fine and keeping track records of each student/teacher is very difficult with different constraints.

## scope of the project

- This is a basic project made with the help of python language.

- The project helps the user in:

1. verifying the credentials of the person who wants to issue the book (student/teacher) by  accepting  name ,ID, phone number etc.
   details from user.
2. checking the availability of the book and how many books are issued in library.
3. registering the details of the book ( book id , author name , book tittle).
4. explaining about the issued date and return date and setting the fine according to (student/teacher).
5. calculating the fine of the person according to due date if person fails to return book on time.

 ## Target users
 This project is based on book issue/return management of library
 
   **Students**

-They issue and return books
-They need to be verified before borrowing
-They may also need to know return dates and fines

**Teachers / Faculty**

-They also borrow books from the library
-Their fine rules or borrowing rules may differ from students

**Library staff / Librarians**

-They manage book records, issue/return transactions, and fines
-They need to track which books are available or issued

**Library administrators / school or college management**

They may use the system to maintain records and monitor library usage
